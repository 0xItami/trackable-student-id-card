01The parts (there are only four)

The main board integrates the ESP32, the 4G LTE modem, the SIM slot, the GPS and the battery charger. So the whole card is really just this board plus a battery, a SIM, and two antennas.

LilyGO T-A7670E board

The whole card: ESP32 + 4G LTE modem (with built-in GNSS) + SIM slot + battery charger, all on one PCB.

LiPo battery

Plugs into the onboard JST. Charges over the board's USB-C.

Data SIM

4G-enabled nano SIM (MTN/Airtel/Glo). Set its APN in the firmware.

Two antennas

LTE → MAIN connector, GPS → GPS connector. Both usually ship with the board.

02How it couples — no wiring, just four attach points

Because the electronics are all onboard, "assembly" is attaching four things to the one board. The blocks inside the dashed outline are already connected on the PCB.

That's the whole hardware build. Everything the old plan wired by hand — the modem, GPS, charger, power capacitor — is already on this board and connected internally. The firmware just talks to it.

03The check

I matched the firmware to LilyGO's official board definition and datasheets. Four things pass; three are for you to verify on the physical board.

pass
Pins match LilyGO's board file. Firmware uses modem on TX 26 / RX 27, PWRKEY 4, POWERON 12, RESET 5 — exactly the T-A7670 definition. GPS needs no GPIO: it is inside the modem, queried with AT+CGNSSPWR / AT+CGNSSINFO over the same UART (verified on the hardware — the external GPS pins produced 0 bytes).
pass
4G band works in Nigeria. The A7670E supports B3 (1800 MHz), the main band for MTN / Airtel / 9mobile 4G — including in urban Zaria.
pass
Power is handled onboard. The board's charger + power design manage the modem's current bursts, so there's no external capacitor or TP4056 to add.
pass
Board target is set. Flash as "ESP32 Wrover Module" with TinyGSM (LilyGO's fork) + ArduinoHttpClient. Mainline TinyGSM has no A7670 support and will not compile.
check
Confirm your board actually has GPS. GNSS + the GPS antenna port exist only on the A7670E-with-GPS variant. Look for a second u.FL connector labelled GPS and a second antenna in the box. No GPS connector = no position source.
check
Keep the LiPo plugged in. The modem's transmit bursts need battery current — some boards won't register on the network on USB power alone. The firmware already sets POWERON high and pulses PWRKEY; if the modem still won't answer, flip MODEM_RESET_LEVEL and re-flash.
check
SIM must be 4G-enabled + right APN. Use a nano data SIM that browses 4G in a phone, and set the matching APN in the firmware (MTN: web.gprs.mtnnigeria.net).

04Physical coupling — how it stacks

Only two things stack: the board and the battery. Antennas face out toward the sky.

05The finished product

Assembled, it's a lanyard/pocket badge printed as a student ID with a live-tracking indicator. Shown next to a real credit card so the thickness is honest.
